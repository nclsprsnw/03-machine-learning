# uber-pickups

</a>

This project focuses on optimizing Uber's driver-user matching in New York City by predicting "hot zones" where demand for rides is high. The goal is to reduce user wait times, which currently lead to cancellations when exceeding 5-7 minutes. Using historical Uber trip data for NYC, the task involves developing algorithms (ideally clustering techniques like KMeans and DBScan) to identify these hot zones, initially for specific hours and days, and then generalizing. The final deliverable will be an interactive map visualization of these hot zones, comparing the results of at least two unsupervised learning algorithms.
